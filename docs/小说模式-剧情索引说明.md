# 小说模式：场景目录、人物此刻与伏笔回声

从最新 AI 楼层的全屏阅读按钮打开小说模式，每次都会定位到最新可阅读楼层的正文开头。右侧“剧情索引”提供三页阅读资料。窄屏可以点击“收起”腾出正文空间，再从顶栏重新打开。

首次使用可在“整理设置”选择工具箱连接方案、覆盖模型和正文标签，然后点击“整理索引”。留空使用当前工具箱连接；正文标签可填写 `正文`、`content` 等，也可留空自动提取可识别的正文。状态栏、脚本、代码及 iframe 源码会跳过。

整理会按时间顺序逐楼调用模型，每次只提供当前楼层及较早已确认的阅读资料，不读取最新故事记忆或后文。长聊天需要多次请求，界面会显示进度；可以随时停止。关闭窗口或酒馆开始生成也会停止整理，已确认的部分保留。再次点击“增量整理”只处理剩余正文。

## 场景目录

模型根据地点、时间、目标或主要冲突划分场景，并生成中性标题。点击目录可定位到对应楼层。

未读场景先显示编号，读到该场景后才显示标题和地点。尚未整理时，目录提供开篇及原文分隔线的基础定位。故事记忆自动隐藏的原始正文默认参与阅读；其他隐藏楼层仍由原有开关控制。

## 人物此刻

读完一楼后，点击楼层末尾的“查看这一刻”；正常向后滚动、经过完整楼层时，也会更新当前时间点。人物资料包括有原文依据的地点、处境、人物关系、知情边界及承诺。点击人物名字或资料中的人物按钮，可查看条目；每项状态能展开来源原文。

第一版以**完整楼层**为时间边界，不把楼层中的每一句单独当作时间点。界面显示“阅读位置”和“资料截至”，尚未整理的楼层会继续使用较早已确认的资料。回到前文时，后来的状态会重新隐藏。

正文姓名高亮使用浏览器 Custom Highlight，不向正文插入包装标签。浏览器不支持高亮时，可通过人物按钮查看。

## 伏笔回声

当较早的线索在后来出现对应回应时，楼层旁会出现“伏笔回声”按钮。点开后可同时查看最早线索和回应句，以及两处原文。

明确对应与“可能关联”分开展示，可能关联标为“待确认”，不会据此把伏笔标成已解答。尚未回应的线索也会保留在此页。所有说明来自模型整理，引用用于核对，不能替代对语义的判断。

## 保存与更新

阅读索引单独保存在当前聊天元数据中，不改写正文，不自动隐藏楼层，也不参与提示词注入。每楼整理后会回读确认保存，失败时不展示未确认的结果。

编辑、改写、切换 swipe、删除楼层或创建不同剧情的分支，会使受影响的索引及其后继失效；较早仍有效的部分保留。重新整理会从失效点继续。修改正文标签会要求按新提取范围重新建立索引。

这版保留了小说模式原有的字号、用户楼层开关及沉浸阅读。阅读位置仅在当前打开的窗口中使用，不保存续读书签。
