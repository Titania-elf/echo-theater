# 小剧场场景配图 v1

## 使用入口

- 新版主界面：正文右侧图片图标。
- 经典主界面：内容工具中的「场景配图」。
- 收藏阅读页：顶栏图片图标。分组收藏可在面板中选择具体一轮。

默认使用当前一轮的完整正文。可以在「正文与人物资料」中调整本次素材、补充人物外观；这些信息只用于配图，不修改剧场正文或酒馆角色卡。

点击「分析画面」后预览中文画面描述和原文摘录，展开后可以编辑全局正负提示词、人物提示词与位置。点击「换个画面」重新运行选景；再次点击「生成图片」沿用当前提示词，重新请求图片。图幅、采样器等使用 Cosmos 当前配置。

接口未安装、未就绪或版本不兼容时，面板显示具体状态。接口随后注册可以自动检测，也可以点击「重新检测」。已保存图片的浏览、采用、下载和导出不依赖 Cosmos 在线。

## 保存语义

- 生成任务固定绑定发起时的正文快照，之后翻页、切聊天不会改变任务归属。
- 新的生成 ID 或正文修改会得到独立配图记录；分支中继承的同一生成结果共享原来的配图候选。
- 主界面把当前采用图放在正文开头，与正文一同渲染。图片与提示词不会加入续写的正文输入。
- 收藏时将各轮当前采用图的元数据一起归档。收藏持有自己的采用图快照，之后可在收藏页单独换图。
- 生成成功后立即保存到酒馆用户文件。保存失败保留本次图片，使用「重试保存」即可，不再次请求生图；在同一页面关闭并重新打开面板也能继续保存。
- 关闭面板不中断选景与生图：任务在后台继续跑，完成后照常保存并成为当前配图，重新打开同一场景可以接着看进度、取消等待或查看结果。面板不在时任务结束会给一条提示。刷新页面会丢弃进行中的任务，所以刷新前应等结果落库或先取消。
- 「暂不展示配图」只移除当前展示选择。v1 不自动删除已保存的图片文件，防止影响收藏或其他引用。
- 「导出图文 HTML」及收藏菜单中的「导出 HTML（含配图）」内嵌图片；完整插件备份也携带图片与记录，恢复时重新上传并改写路径。

## 对接约定

供应方按 [Cosmos 公开接口需求](./Cosmos-Vision-公开接口需求-v1.md) 与 [TypeScript 定义](./cosmos-vision-public-api-v1.d.ts) 开发。

客户端：`src/core/cosmosVisionBridge.js`；DTO 与校验：`illustrationData.js`；图片与记录保存：`illustrationStore.js`；备份/导出：`illustrationPortability.js`；交互面板：`src/ui/illustrationWindow.js`。

设置只记录 `illustration_index` 的小型文件指针。正文、角色设定和图片 base64 不写入该索引。图片文件为 `/user/files/titania-illustration-*.png|jpg|webp`，场景记录为 `/user/files/titania-scene-*.json`。

## 验证

```sh
npm run test:illustration
npm run build
```

测试使用 jsdom 与模拟 API/文件服务，覆盖选景预览、提示词修改、旧分支收藏、取消和迟到结果、保存失败重试、目标切换、关窗后台运行与重开接管、收藏字段保留、跨安装备份恢复与 HTML 内嵌图片。测试模拟对象不会打包进插件。

实际 Cosmos 公开接口、真实 NovelAI/ComfyUI 生成、移动端视觉布局仍需在接口完成后联调。最终联调重点：提供的上下文确实没有混入当前聊天；画风预设没有重复叠加；取消没有中断其他任务；图片 MIME/尺寸与接口约定一致。
